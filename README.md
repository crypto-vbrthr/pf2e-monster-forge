# PF2e Monster Forge

Erste Ausbaustufe: ein einfacher, datengetriebener Monsterrohling-Generator für Foundry VTT + PF2e.

## Features in 0.1.0

- Monsterlevel 0 bis 20
- Rollen-Presets: Haudrauf, Soldat, Plänkler, Zauberwirker
- Größenwahl
- Trait-Auswahl
- Werte-Overrides für HP, AC, Rettungswürfe, Angriff und Schaden
- Vorschau im Dialog
- Actor-Erstellung als PF2e-NPC
- Deutsch/Englisch über Foundry-Lokalisierung

## Installation zum Testen

Den Ordner `pf2e-monster-forge` in Foundrys `Data/modules/` kopieren und Foundry neu starten.
