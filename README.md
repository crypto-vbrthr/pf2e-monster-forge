# PF2E Monster Forge

A Foundry VTT module for Pathfinder 2e Remastered that generates fully playable NPC monsters based on PF2E monster creation guidelines.

The goal of Monster Forge is not to replace manual monster design, but to rapidly generate a complete and editable foundation for custom creatures, NPCs, bosses, and encounters.

---

# Features

## Monster Generation

Generate complete PF2E NPC actors with:

* Level
* Role
* Monster Family
* Size
* Elite / Weak / Normal adjustments
* Attributes
* Armor Class
* Hit Points
* Perception
* Saving Throws
* Skills
* Speeds
* Languages
* Senses

Generated values follow PF2E creature-building benchmarks.

---

## Monster Families

Monster families provide thematic presets including:

* Suggested role
* Suggested size
* Traits
* Attack profiles
* Statistical tendencies

Examples:

* Dragon
* Undead
* Fey
* Celestial
* Fiend
* Beast
* Construct
* Custom

---

## Attack Generation

Generate one or more attacks using predefined profiles.

Examples:

* Claw
* Bite
* Jaws
* Slam
* Sword
* Greatsword
* Spear
* Staff
* Spell Ray

Attack names are localized.

---

## Resistances, Weaknesses and Immunities

Supports automatic generation and actor creation for:

* Resistances
* Weaknesses
* Immunities

Values are previewed before creation and transferred directly to the generated PF2E actor.

---

## Special Abilities

Generate abilities automatically from monster traits or select them manually.

Examples:

* Regeneration
* Aura
* Death Burst
* Swallow Whole
* Teleport
* Invisibility
* Spellcasting

Special abilities support:

* Action costs
* Saving throw buttons
* Damage roll buttons
* Localized descriptions

---

## Spellcasting

Generate complete spellcasting packages.

Configuration options:

### Tradition

* Arcane
* Divine
* Occult
* Primal

### Spell Style

* Artillery
* Control
* Support
* Summoning

### Spell Count

* Few Powerful Spells
* Bestiary Style
* Full List

Generated spellcasters receive:

* Spellcasting Entry
* Spell DC
* Spell Attack Modifier
* Real PF2E Spell Items

Spells are imported directly from the PF2E spell compendium and automatically assigned to the created actor.

---

## Family and Trait Spell Weighting

Spell selection is influenced by:

* Monster Family
* Creature Traits
* Chosen Spell Style
* Chosen Spell Tradition

Examples:

### Fire Creature

Prefers:

* Fireball
* Breathe Fire
* Wall of Fire
* Volcanic Eruption

### Undead Creature

Prefers:

* Harm
* Bind Undead
* Vampiric Feast
* Spirit Blast

### Fey Creature

Prefers:

* Charm
* Suggestion
* Confusion
* Dominate

This creates more thematic spellcasters without requiring manual spell selection.

# Intended Workflow

1. Select a monster family.
2. Adjust role and level.
3. Choose traits.
4. Configure attacks.
5. Configure spellcasting (optional).
6. Preview the creature.
7. Create actor.
8. Apply final manual adjustments if desired.

Most creatures can be generated in under one minute.
