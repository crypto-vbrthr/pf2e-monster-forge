# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-03

### Added

* Initial public release of PF2E Monster Forge
* Monster generation based on PF2E creature-building guidelines
* Role-based creature presets
* Monster family presets
* Size selection
* Elite, Normal and Weak adjustments
* Automatic attribute generation
* Automatic Perception generation
* Automatic saving throw generation
* Automatic skill generation
* Attack profile generation
* Resistance generation
* Weakness generation
* Immunity generation
* Sense generation
* Language generation
* Automatic special abilities based on traits
* Manual special ability selection
* Localized interface (English and German)
* Localized attack names
* Localized trait display
* Spellcasting support
* Arcane, Divine, Occult and Primal traditions
* Artillery, Control, Support and Summoning spell styles
* Automatic spell package generation
* Family and trait-based spell weighting
* Automatic PF2E spell import from compendiums
* Automatic Spellcasting Entry creation
* Preview window for generated creatures
* Direct PF2E NPC actor creation
